# 华文小岛

华文小岛是一个网页游戏站，给新加坡小学生（P2–P6）练华文，**听、说、读、写**都有。站里有两类内容：

- **17 个会动的街机游戏**：华文就是游戏规则，不是先答题再给奖励；
- **14 个练习**：沿用 1.0 版的练习本。

每天有一条 12–15 分钟的“今日航线”，答对的字会变成饼干，喂大孩子自己挑的字宠。

这个站是为家里两个孩子做的：P4 哥哥（约 10 岁）和 P2 妹妹（约 8 岁），两个人都有华文底子。所以题库按各年级**偏上**的难度出，接近中国部编版同年级（见 [SPEC.md](SPEC.md) §2）。

## 1. 怎么玩

- **在线玩**：https://hzhan7.github.io/huawen-island/ 。iPad、手机、电脑都能用，建议用 Safari 或 Chrome。
  - 这个网址是 GitHub Pages 发布的 `docs/index.html`，要等仓库推送之后才会更新。
  - 2026-09-19 看的时候，线上还是 1.0 版，只有 14 个练习。本 README 写的是仓库里的 3.0 版。
- **本机玩**：先按第 8 节构建，再用浏览器直接打开 `docs/index.html`。
  - 需要联网：字体、笔顺库（hanzi-writer）和物理引擎（matter.js）都从 CDN 加载。
- **第一次打开**：
  1. 建一个档案：名字、头像、年级。
  2. 孩子自己挑一颗字宠蛋。
  3. 年级可以随时切换。
  4. 一台设备可以放好几个孩子的档案。
- **声音**：
  - 朗读用的是浏览器自带的中文语音，iPad 和 Mac 的 Safari 都有。
  - “说”的游戏会请求麦克风。不给也能玩，例如声音火箭会改成跟着节拍敲。

## 2. 17 个街机游戏：华文怎么变成玩法

首页是一张会动的游戏岛地图，四座岛各对应一项技能：听·灯塔岛、说·舞台岛、读·书树岛、写·毛笔山岛。所有街机的共同规则：

- **关卡和解锁**：每个游戏 10 关（兄妹拔河 8 关）。通关并拿到 ≥2 颗星，才解锁下一关。越往后越快，场景从白天变成黄昏，再变成夜晚。
- **心和后果**：大多数游戏有 3 颗心，P2 在声调跑酷、切字忍者里有 5 颗；合成大汉字和兄妹拔河不用心，分别按罐子堆满、绳子拉过线定输赢。错了有游戏里的后果，比如桥塌了、鸟被钢盾弹回来、顾客把托盘推回来，而不是弹一个 ✗。
- **错题本只记华文错误**：手没跟上、来不及、乱按，都不算错题，只有真正的华文判断错了才记进去。
- 标 **3.0** 的 6 个游戏还要过第 7 节的“五关”检验。它们的玩法依据是 [research/GAME_SHORTLIST.md](research/GAME_SHORTLIST.md) 第 2 节。

### 听（5 个）

| 游戏 | 华文怎么变成玩法 |
|------|------------------|
| 🎈 气球射击 | 听一个词，小猫炮台去戳写对的那只气球。其他气球上是同音、近音或形近的错误写法，打错就扣心。 |
| 🧺 天降汉字 | 听一个词，左右移动篮子，按顺序接住这个词的每个字。接到同音、近音的干扰字就扣心。 |
| 🐸 青蛙过河 | 先听收音机讲一个故事（不显示原文），再按问题跳上写着正确答案的荷叶。跳错了，荷叶翻沉、青蛙落水。 |
| 🪢 兄妹拔河（3.0） | 听到一个词或“晴天的晴”，抢先拍中写对的字卡，把绳子拉过来。卡上不注拼音；拍错了手会被锁住。可以兄妹同屏对战，两边按各自的年级出卡；也可以一个人挑战岛主。 |
| 🐲 声调跑酷（3.0） | 在屏幕上画出字的声调（ˉ ˊ ˇ ˋ），给小龙铺桥：一声是平桥，二声是跳台，三声是吊桥，四声是滑梯。画错了桥会塌，小龙掉进海里，这个字过一会儿再考一次。 |

### 说（2 个）

| 游戏 | 华文怎么变成玩法 |
|------|------------------|
| 🚀 声音火箭 | 跟着卡拉OK的跳跳球大声读课文或绕口令，声音越大火箭推力越大。一句读完燃料不够，火箭就掉回来，要重读。没有麦克风时，改成跟着节拍点。 |
| 🥁 绕口令节拍 | 绕口令的每个字踩着鼓点跳进鼓圈，孩子一边读一边敲鼓。关卡越高，速度越快。 |

### 读（5 个）

| 游戏 | 华文怎么变成玩法 |
|------|------------------|
| 🏎️ 华文赛车 | 知识题（拼音、成语、关联词……）的选项变成赛道上的门，开车穿过正确的门。撞错门会打滑、扣心，并显示讲解。 |
| 🐍 贪吃蛇排句子 | 小蛇按通顺的语序，一口一口吃掉词语果子，排成一句话。吃错顺序就扣心。 |
| 🃏 拼音翻翻乐 | 翻牌，把词语和它的拼音配成对。只有翻开“明明见过、知道不对”的牌才扣心。 |
| 🍜 华文小吃店（3.0） | 读懂顾客的点单，做出一模一样的菜。点单会考数量和量词、“不要”、颜色、摆放位置、先后顺序。食材格子只有图、没有字。做错了，顾客把托盘推回来，还会指出哪一句没做对。 |
| 🐦 组词弹弓（3.0） | 弹弓上的小鸟写着一个字，要打中能和它组成词的字怪（火＋车＝火车），堡垒才会炸飞。组不成词的字怪用钢盾把鸟弹回来。 |

### 写（5 个）

| 游戏 | 华文怎么变成玩法 |
|------|------------------|
| 🔨 打地鼠找错字 | 木牌上挂着一句有错字的话。先敲举着错字的地鼠，再敲举着正确字的地鼠。 |
| 🎣 偏旁钓鱼 | 木牌上有一个字，孩子要钓起写着正确偏旁的那条鱼，拼出新字。钓错了，鱼会挣脱逃走。 |
| 👾 写字打怪兽 | 在田字格里一笔一笔写字。写对一笔，大炮就打怪兽一下；写错一笔，怪兽往前跳一步。关卡顺序是描红、照写、听写。 |
| 🫙 合成大汉字（3.0） | 把部件球丢进罐子，碰到能组成字的搭档（氵＋青＝清）就合成新字，并读出“清，清水的清”。丢错了，部件变成石头占地方；堆过红线就输。 |
| 🥷 切字忍者（3.0） | 按字的结构下刀：左右结构竖着切，上下结构横着切，包围结构画个圈，独体字是炸弹，别切。所有字块长得一模一样，只能靠读懂结构来判断。 |

## 3. 14 个练习（练习本）

这是 1.0 版的“题卡式”练习，每轮 3–5 分钟，适合安静地做一会儿。

| 技能 | 练习 |
|------|------|
| 听 | 顺风耳（听音选词）· 故事电台（听故事答题）· 听写大挑战（在田字格里手写） |
| 说 | 朗读小明星 · 绕口令擂台（计时破纪录）· 小小主持人（看图会话，对齐口试） |
| 读 | 知识闯关（拼音、成语、关联词、病句、古诗等 22 类）· 拼音连连看 · 句子排排队 · 阅读小侦探 |
| 写 | 笔顺描红（先看、再描、最后默写）· 偏旁魔术 · 错字侦探 · 小作家（造句、看图写话） |

奖励和复习：

- 每轮得 0–3 颗星，换成小红花；小红花攒够了，可以解锁印章。
- 答错的题自动进错题本。重练时答对 2 次，就从错题本里移出。

## 4. 元游戏：让孩子每天想回来

实现在 `parts/12_meta.js`，设计依据是 [research/GAME_SHORTLIST.md](research/GAME_SHORTLIST.md) §3。

- **今日航线**（大约 12–15 分钟，共 4 站）：
  1. 🌾 **丰收**：打一局街机，把今天该复习的字“收回来”。
  2. ✨ **新字**：认识今天的新字，每天 P2 4 个、P3–P4 5 个、P5–P6 6 个。每个字可以听读音、看组词，有的还有例句。
  3. 🎮 **今日游戏**：每天换一个指定游戏，优先排“华文就是规则”的那几个，今天的新字会先出现。
  4. 🎁 **宝箱**：里面有什么，事先就告诉孩子：2 朵小红花、1 块金饼干和今天的航线章。
- **字卡图鉴**：每个字是一张卡，卡的等级就是掌握程度。
  - 灰卡：见过；
  - 铜卡：答对过；
  - 银卡：隔天又答对；
  - 金卡：按第 1、3、7 天的间隔都答对。

  同一天刷再多也不升级。到了复习日的字，会进第二天的“丰收”。
- **字宠**：孩子从本年级字最多的几个部首家族里，自己挑一颗蛋，比如氵是水龙、木是树精、火是火狐、日是太阳鸟。
  - 当天答对的字变成“字形饼干”，每天最多 10 块，用来喂蛋、喂宠物。
  - 蛋大约 2 天孵出来。宝宝吃满 20 份，长成少年。
  - 少年再加上这个家族的字全部金卡，就变成“霓虹”，这一步只看掌握程度。
  - 几天没来，宠物只是睡着了。
- **灯塔**：
  - 每完成一天的航线，自己的灯塔亮一层；第 3、7、30 天放烟花。
  - 每周一送 1 张“雾天卡”，最多存 2 张。漏了一天会自动用掉，连胜不断。
  - 没有雾天卡时断了，灯塔只暗一层，**不清零**。
  - **兄妹灯塔**：最近 14 天玩过的档案，当天都完成航线，它才亮。

**设计底线**（全部照办）：

- 完全不涉及钱，小红花只是站内的星星；
- 没有抽奖，也没有隐藏概率：蛋是孩子自己挑的，宝箱里有什么提前写明；
- 宠物不死、不病，也不用“它会伤心”来施压；
- 兄妹之间不能互相偷东西，也没有聊天；
- 奖励看学得好不好，不看玩了多久：同一关一天里反复刷，小红花会递减，字卡也不会多升级；
- 家长可以设每天的时长上限（见第 5 节）。

## 5. 家长设置

- **档案**：每个孩子一个档案，里面有名字、头像和年级（P2–P6）。
- **每日时长上限**：可以选不限、15、20、30、45、60、90 或 120 分钟。
  - 这一项平时是锁着的。要点“家长修改”，并通过家长验证，才能改。
  - 只算真正在玩的时间：页面在前台，而且正在玩一局，或者 90 秒内点过、按过键。
  - 还剩 2 分钟时会提醒。时间到了，正在玩的那一局可以玩完（最多再给 3 分钟），星星和小红花照常结算，然后出现“休息”页。
  - 新建的档案，默认沿用家里最严的那个上限，免得孩子新建档案来绕开。
  - 参考：新加坡卫生部建议，7–12 岁孩子每天的休闲屏幕时间少于 2 小时（出处见 GAME_SHORTLIST §3）。
- **家长验证**：
  - 修改时长上限、删除档案之前都会弹出。孩子看到的是“请爸爸妈妈来”。
  - 家长要算一道“两位数 × 一位数”，自己输入答案，不是选择题。
  - 答错了换一题；连错 3 次，锁 60 秒。
- **存档**（档案页底部，`parts/13_parent.js`）：
  - 自动存档：每一步进度都马上写进浏览器（localStorage）；玩完一局回地图时角落会闪“💾 进度已自动保存”；存不上时会提醒家长。
  - 存档点（存在 IndexedDB）：每天第一次打开自动存一个（留 7 天）；可以随时手动存、起名字（留 10 个）；每次恢复之前自动备份现在的进度（留 3 个）。
  - 导出 / 导入存档文件：iPad 上走分享面板（可“存储到文件”、AirDrop），电脑上直接下载。浏览器清数据、Safari 的 7 天清理规则、换设备、网页版和单机版之间搬进度，都靠这个文件。下载不方便时还能用文字复制、粘贴。
  - 恢复和导入都要过家长验证。
- **声音检查**（档案页底部）：当场响一声、读一句，逐项说明音效、静音模式、朗读哪一步不通，以及怎么修。

**声音为什么以前会时有时无**（3.1 已修，见 `parts/10_core.js` 的 AUD 和 TTS）：iPad 切后台、锁屏、来电之后，WebKit 把 AudioContext 置为 `interrupted`，只认 `suspended` 的代码不会恢复；朗读引擎卡在“忙”的时候新句子会一直排队；iPad 开着静音时网页声音默认也静音。现在所有 AudioContext 统一登记，点屏幕时一起恢复；朗读 1.5 秒没开口就重说，4 秒没开口就放弃并显示字幕，下次点屏幕重新预热；Safari 17+ 设 `navigator.audioSession.type = 'playback'`，静音模式下照常出声（用麦克风时临时切回 `auto`）。

## 6. 两个版本的区别

构建时同一份源码会输出两个版本，**两边的进度不互通**。

|              | GitHub Pages 版（`docs/index.html`） | claude.ai Artifact 版（`dist/index.html`） |
|--------------|--------------------------------------|--------------------------------------------|
| 怎么打开     | 公开网址，不用登录                   | 在 claude.ai 里打开，需要 Claude 账号      |
| 进度存在哪   | 这台设备的浏览器里（localStorage）；换设备、清浏览器数据前要先在「档案 → 存档」导出文件 | 云端存档，换设备也能接着玩；云端连不上时，进度先存在这台设备上 |
| AI 老师点评  | 没有                                 | 有：小作家（造句、看图写话）和小小主持人（会话）可以请 AI 老师点评，需要大人同意使用 Claude |
| 游戏内容     | 相同                                 | 相同                                       |

云端合并的规则是：数值取较大的，日期和集合取并集。所以两台设备同时玩，进度不会减少，也不会翻倍。

## 7. 调研依据

3.0 的设计来自 [research/GAME_SHORTLIST.md](research/GAME_SHORTLIST.md)，它综合了 `research/` 下的几类材料：

- GitHub 游戏仓库核验：`gh_*_verified.md`，以它们为准；`gh_*.md` 是原始笔记；
- 儿童游戏偏好：`web_kids.md`；
- 学中文 App 的做法：`web_apps.md`；
- 其他：`scout_gemini.md`。

要点：

- **1.0 为什么不行**：它把华文当成门票，先答题、再给一个勾，画面不动，也没有明天回来的理由。有研究发现，7–8 岁孩子自由选择时，玩“学习内容就是玩法”那个版本的时间，是“答题换游戏”版本的约 7 倍（Habgood & Ainsworth 2011，样本只有 16 人）。
- **3.0 每个新游戏要过“五关”**：
  1. **换皮测试**：把字换成色块，游戏还能玩通吗？能，就不合格。
  2. **乱按测试**：乱按会不会很快输？
  3. **决策点**：每一次操作都要有华文判断。
  4. **游戏内后果**：错了要在游戏里出事，而不是弹一个 ✗。
  5. **错题本不被污染**：手没跟上不算华文错题。
- **证据等级**：文中每个说法都标了等级。【实测】是亲手跑出来的数字，【原文】是来源原话，【推断】是设计判断。**所有“孩子会喜欢”的说法都属于推断**，还没有让这两个孩子实际试玩过。
- **还没做的部分**：GAME_SHORTLIST 推荐了 15 个游戏，第一批做了其中 6 个。元游戏里的字田、装扮、段位、每周合作 Boss 还在计划中。
- **家长待看**：[research/MENU_FOR_PARENT_REVIEW.md](research/MENU_FOR_PARENT_REVIEW.md) 列出了华文小吃店的全部菜名和量词，并标注“新加坡说法 / 中国说法”，需要家长过目。

## 8. 构建方法

```bash
# 1) Python 环境：pypinyin 用来核对拼音（必需）；hanzi_chaizi 用来复查合成配方的拆分（可选）
python3 -m venv .venv && .venv/bin/pip install pypinyin hanzi_chaizi

# 2) 笔顺数据（只在构建时读取，只把用到的字内嵌进页面）
(mkdir -p vendor && cd vendor && npm pack hanzi-writer-data@2.0.1 && tar xzf hanzi-writer-data-2.0.1.tgz)

# 3) 构建：同时输出 dist/index.html（Artifact 版）、docs/index.html（Pages 版）和 build/report.txt（校验报告）
.venv/bin/python build/build.py            # 有错误也会输出页面，错误写在报告里
.venv/bin/python build/build.py --strict   # 有错误就不输出
```

- `parts/` 下的 `*.js` 按文件名顺序自动打包。页面上限是 16MB。
- 构建时会用 node 做语法检查；没有 node 就加 `--no-node`。
- 校验报告 `build/report.txt` 检查这些内容：
  - 字段和答案下标；
  - 用 pypinyin 交叉核对拼音；
  - 错字下标、笔顺缺字、朗读时“地”的读音；
  - 3.0 新栏目：合成配方拆分、组词弹弓的干扰字真的组不成词、字的结构覆盖、菜单的量词和颜色一致性。
- 想构建到别的目录（不覆盖正式产物），可以用 `--out`、`--report`、`--pages-out`、`--parts-dir`。

**测试（无头 Chrome 试玩和截图）**：`tools/shot.js` 需要 puppeteer-core 和本机的 Google Chrome（路径写死为 `/Applications/Google Chrome.app`）。

(cd tools && npm i puppeteer-core)

## 9. 题库与数据文件

所有题库都在 `content/*.json`，按年级（`p2`…`p6`）→ 栏目组织，全部用简体字，拼音带调号。格式和出题规则见：

- [SPEC.md](SPEC.md) §2：1.0 的 13 个栏目；
- [SPEC_V3.md](SPEC_V3.md) §3：3.0 的新栏目。

3.0 的新数据有一条规则：**每个年级只能用本年级及以下出现过的字**。

| 文件 | 栏目（每个年级的条数） | 给谁用 |
|------|------------------------|--------|
| `words.json` | `words` 50 个听写词、`chars` 30 个写字表字 | 听写、笔顺、天降汉字、写字打怪兽、翻翻乐、声调跑酷、字卡图鉴 |
| `listen.json` | `pick` 20 道听音选词、`stories` 6 篇听力故事 | 顺风耳、故事电台、气球射击、青蛙过河、兄妹拔河 |
| `speak.json` | `readaloud` 8 段朗读、`twisters` 5 条绕口令、`talk` 6 个会话话题 | 朗读、绕口令、小小主持人、声音火箭、绕口令节拍 |
| `read.json` | `order` 15 道排句、`passages` 4 篇阅读 | 句子排排队、阅读小侦探、贪吃蛇 |
| `write.json` | `build` 15 道偏旁、`typo` 15 道错字、`compose` 8 道写作 | 偏旁魔术、错字侦探、小作家、偏旁钓鱼、打地鼠、合成大汉字 |
| `quiz_a.json` / `quiz_b.json` | `quiz` 50 道知识题（a = P2–P4，b = P5–P6） | 知识闯关、华文赛车 |
| `ext_recipes.json` | `recipes` 52–57 条合成配方，`chains` 连环合成 | 合成大汉字 |
| `ext_jg.json` | `jg` 131–180 个字的结构（左右、上下、包围、独体……） | 切字忍者 |
| `ext_zuci.json` | `zuci` 29–30 组：中心字、能组词的字、组不成词的干扰字 | 组词弹弓 |
| `ext_menu.json` | `menu` 10–32 道菜，`menuwords` 颜色、位置、量词搭配 | 华文小吃店（家长过目稿见 research/MENU_FOR_PARENT_REVIEW.md） |
| `ext_bushou.json` | `bushou` 每个字的部首和家族，`bushou_stats` 家族统计 | 字宠蛋的部首家族 |
| `_sample.json` | 每个栏目 1–2 条样例 | 只给构建自测用，默认构建会跳过 |

`build/build.py` 会把这些数据并进页面里的 `HW_DATA`。3.0 的新栏目缺失时，游戏会用内置的兜底数据。
